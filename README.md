# 🎨 BFAliNoteColors

**Notalarını Kendi Renklerinle Özelleştir!**

BFAliNoteColors, Friday Night Funkin' için geliştirilen, nota oklarının renklerini kişiselleştirmenizi sağlayan bir mod projesidir. Kendi renk kombinasyonlarınızı oluşturarak oyun deneyiminize özgün bir görünüm kazandırın!

## ✨ Özellikler

- 🎨 **Özel Nota Renkleri:** Nota oklarının renklerini kişiselleştirin.
- 🌈 **Renk Özelleştirme:** Kendi renk kombinasyonlarınızı oluşturun.
- 🖌️ **Kişisel Renk Paletleri:** Standart renklerin dışına çıkın.
- ⚙️ **Kolay Yapılandırma:** Renk tercihlerinizi yönetin.
- 🎵 **FNF Desteği:** Friday Night Funkin' deneyimiyle uyumlu yapı.

## 🎮 Proje Hakkında

BFAliNoteColors, oyuncuların standart nota renkleri yerine kendi tercih ettikleri renkleri kullanabilmelerini amaçlar.

Kendi renklerini seç, tarzını yansıt ve oyununa kendi imzanı at!
